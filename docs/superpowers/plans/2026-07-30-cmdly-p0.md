# CMDLY P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship P0 of CMDLY — a Next.js 15 PRA dashboard with better-auth login, a demo/live DataProvider seam, and a working "Vue d'ensemble" fed by simulated data.

**Architecture:** App Router + Server Components. Every page/route talks to a `DataProvider` selected by `CMDLY_MODE` (`demo` default). Auth via better-auth on better-sqlite3; a Next.js middleware guards all pages and `/api/**` except auth routes. Overview renders KPIs, an 8-host grid with sparklines, and a fleet time-series chart — all from the demo provider.

**Tech Stack:** Next.js 15, TypeScript strict, Tailwind, shadcn/ui, Recharts, lucide-react, sonner, zod, SWR, better-auth, better-sqlite3, Vitest.

## Global Constraints

- Node 20+, pnpm. TypeScript **strict**.
- Bind `127.0.0.1:8700` only. Never expose publicly.
- Accent color `#2E5AAC`; light/dark themes.
- `CMDLY_MODE=demo` is the default; P0 ships **no** destructive/live operations.
- No arbitrary shell; no secrets in client bundle or logs.
- Inventory (8 hosts) is the single source of truth: reverseproxy 10.10.10.10 (DMZ), nextcloud 10.10.20.10, postgresql 10.10.20.11, openldap 10.10.20.20, wazuh 10.10.20.30, monitoring 10.10.20.31 (all SRV), bastion 10.10.30.10 (MGT), backup-ovh 10.20.20.40 (OVH).

```ts
export type Zone = "DMZ" | "SRV" | "MGT" | "OVH";
export interface Host { name: string; ip: string; zone: Zone; role: string; vmid: number | null; terraform: boolean; }
export const INVENTORY: Host[];
export const HOST_NAMES: string[];
export function getHost(name: string): Host | undefined;

// lib/data/types.ts
export interface VmStatus { name: string; ip: string; zone: Zone; status: "running"|"stopped"; cpu: number; mem: number; uptime: number; }
export interface MetricPoint { t: number; v: number; }
export interface MetricSeries { instance: string; points: MetricPoint[]; }
export type RangeKey = "1h"|"6h"|"24h";
export interface Alert { fingerprint: string; severity: "critical"|"warning"|"info"; name: string; instance: string; startsAt: string; }
export interface BackupEntry { location: "local"|"ovh"|"r2"; name: string; sizeBytes: number; createdAt: string; }
export interface HealthSummary { vmsUp: number; vmsTotal: number; cpuGlobal: number; ramGlobal: number; diskMax: number; lastBackupAgeSec: number|null; ipsecUp: boolean; activeAlerts: number; mode: "demo"|"live"; }

// lib/data/provider.ts
export interface DataProvider {
  getVms(): Promise<VmStatus[]>;
  queryRange(metric: "cpu"|"mem", range: RangeKey, instances?: string[]): Promise<MetricSeries[]>;
  getAlerts(): Promise<Alert[]>;
  getHealth(): Promise<HealthSummary>;
}

// lib/data/index.ts
export function getProvider(): DataProvider;   // reads process.env.CMDLY_MODE

// lib/format.ts
export function pct(n: number): string;         // "42%"
export function ageLabel(sec: number|null): string; // "3 h", "—"
export function bytes(n: number): string;
```
